## Findings

1. **P1 — selected execution context does not control green logic indication.** `src/App/LadderEditorCanvas.cs:277` reads `Snapshot.Elements` by instruction ID, whereas `SelectObservationContext` and `InstructionPresentationFor` in `LadderEditorCanvas.Monitoring.cs` select exact observations. `DrawRecursiveConditions` uses the former for contact/comparison colors. Execute the same block in two paths with FALSE then TRUE and select the first path: readout says FALSE while the symbol remains green from the global last invocation. Selecting a missing context can still leave green symbols. Resolve both indication and text through the same validated context and suppress indication when that context is unavailable. Add a native canvas assertion for opposing contexts and a missing context, plus lifecycle suppression.

2. **P2 — invalid/mismatched drafts are mislabeled as no loaded program in production.** `SimulatorShell.InstructionMonitoring.cs:13` and `SimulatorShell.cs` monitor refresh paths pass null when `_ladderMonitorMatchesLoadedProgram` is false. The canvas therefore calls `PresentSnapshot` with null, returning NoProgramLoaded. The presenter's explicit DraftMismatch/InvalidDraft support is not wired into production. Reproduce by loading a valid program, running, and editing an executable operand: monitor should explain that the draft differs, rather than claim no program is loaded. Pass explicit monitor eligibility/reason alongside the retained publication and bind only after validation. Test actual shell routes for invalid draft, valid mismatch, watch-only edit, equivalent undo, reload, and reset.

3. **P2 — inline layout remains too tall for the full editor and numeric fallback has incorrect arity.** `LadderEditorCanvas.Monitoring.cs:111-115` allocates every terminal a fixed 380×194 rectangle; `DrawTerminalObservation` adds title/status and up to six detail rows, and condition annotations add three rows. Parent reports clipping in the full-shell counter render at 1600×900. This is not solved by standalone canvas screenshots. Compact default CTU/CTD presentation should retain current count vs configured preset and input/done, with detailed effects/context in the inspector. Ensure selected terminal reveal and scrolling use its actual bounds at every required zoom/DPI. Separately, `CompactRows` unavailable numeric fallback always shows Source B, even for unary operations, and omits Source C for NORM/SCALE. Use `LadderNumericOperationRules` for exact operand arity in both monitored and unavailable states.

4. **P2 — history exposes images but cannot inspect the retained instruction observations.** `SimulatorShell.ScanInspection.cs:ShowScanHistoryRow` displays phase/image/diagnostic data only. Selection deliberately leaves the live inspector unchanged, and there is no alternate historical instruction/context inspector. Thus a retained scan's actual consumed operands and stored-after values cannot be viewed after the current scan advances, despite the contract's historical observation/detail requirement. Add a read-only history-specific instruction/context selection bound to the selected record's publication; keep live selection unchanged. Prove old selected attempt values remain stable across later scans and show explicit eviction instead of silently presenting a different record.

## Coverage and integration limitations

`PresenterEveryCatalogKeyAndDisposition` checks catalog set equality, which is valuable, but synthesizes the same numeric A/destination observation for every key, including counters, timers and control flow. It does not establish real bindings or operation arity. Add runtime-to-presenter cases per real family and exact arity assertions, particularly unary math, NORM/SCALE, FORMAT_TEXT failure-clears, false-enable timer/counter evaluation, and CALL phase bindings once Task 7 lands. Parameterized CALL and scoped instance final values remain dependencies, not completed Task 6 acceptance. Performance budgets and full viewport/DPI/zoom/native matrix remain unverified by this review.

Positive findings: instruction-time StoredAfter is separate from explicitly labeled Final snapshot; missing selected context does not substitute another observation in the pure presenter; origin identity checks reject mismatched load/generation/session; retained lifecycle observations have distinct status; normalized and truncated values have explicit labels; inspector text is read-only and wraps.
