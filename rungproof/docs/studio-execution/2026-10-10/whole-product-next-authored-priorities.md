## Recommended existing lessons, in order

1. **Lab10.4 Motor ENUM State (`lab-10-04-motor-enum-state`).** Smallest reusable typed-state learner workflow. `AuthoredLessonLadderPrograms.Motor` already has explicit Start/Stop/fault/reset inputs, latched fault/start-edge memory, Running output and Stopped/Running/Fault ENUM. Invalid current draft must stop without fallback. Preserve source semantics; do not call motor output a measured shaft feedback signal. Reset must restore actual mounted motor homes and clear the declared state. This is a qualification task first, not a new plant rewrite.

2. **Lab10.2 Chicken Label Print (`lab-10-02-chicken-label-print`).** Highest-value next richer physical feedback chain after the simpler state workflow. `AuthoredLessonLadderPrograms.Chicken` formats REAL weight into STRING label, drives print_request until print_complete, then apply_request until application_complete. Qualify actual weighed-product/label validity inputs, rendered exact label text, printer/application acknowledgement on the next accepted scan, and observable print/apply process. Compile-valid wrong omission of acknowledgement or data permissive must produce different behavior. Test zero/invalid weight/data, unavailable printer, Stop/resume/Reset, accepted20/40/100 cadence, exact custom draft joint reopen and invalid-current rejection. Source inspection must first distinguish actual plant-generated acknowledgements from manual PC fixtures; do not claim a closed physical loop merely from input tags or authored prose.

3. **Lab10.1 Drive Alarm-Code String (`lab-10-01-drive-alarm-code-string`).** Existing text diagnostic lesson, not a physical drive troubleshooting simulator. `AuthoredLessonLadderPrograms.Drive` uses ContainsCode token matching, string-valid input and reset to drive Boolean indication. A valid wrong comparison must visibly misclassify a supplied text case. Preserve exact text/draft through joint reopen; invalid current must reject. Label supplied alarm text and commanded indication honestly; no vendor alarm interpretation, real drive fault feedback or commissioning claims.
