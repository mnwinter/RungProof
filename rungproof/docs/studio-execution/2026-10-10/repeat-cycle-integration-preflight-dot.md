# Repeat-cycle integration preflight: Dot

Read-only inspection of current Main Run/Stop/Reset/load/draft/force hooks, shared plant callback and accepted session pipeline. Approved protocol remains in repeat-cycle-studio-implementation-plan.md. No product edits, build or engine run.

1. Unchanged current Run after Stop skips EnableVirtualControllerProgram, preserving controller memory and the partially completed plant. Do not create a fresh trial in RunActiveController. Preserve Incomplete/historical status until explicit Reset even if physical home happens to be true; retained CTU memory can differ from initial conditions.
2. Fresh scene composition attaches before a controller exists. Stage its Reset epoch, then resolve bindings and begin only after Shell.AttachVirtualController establishes the current accepted program identity. A fresh tag-only draft must remain blank and unavailable, never receive the QA reference.
3. Changed valid draft Enable(resetScene:false) creates a new session/scan clock but preserves actual plant pose. Retire the former observation; non-home new program is unavailable until Reset. A new session number alone does not prove a new home trial.
4. Capture immutable BeforePlant/AfterPlant immediately around actual AdvanceSimulation in the shared accepted callback. Clear pending capture before each accepted cycle and stamp it with runtime/session reference, epoch and scan number. ScanCompleted must reject missing or stale pairs; a cached pair from a failed tick cannot qualify the next event.
5. Observe only ScanCompleted after actual projection, not SnapshotPublished. Run, Stop, Reset and force changes can publish snapshots without a plant tick. Post-plant capture must work with history disabled and must not use current UI point dictionaries later on another frame.
6. Retire on semantic program/binding/layout changes and on IntegratedDraftChanged mismatch. Use the same execution identity excluding WatchVariables as current Run; a watch-only edit must not erase observation. Unsupported external/challenge/other-scene paths hide the card and retire subscriptions.
7. Force use invalidates immediately at the force hook, including forces that are applied and removed before another scan. Clearing a force does not restore an already contaminated trial; Reset is required. Missing/wrong DINT or generated PC bindings must never default to zero/false.
8. Stop must preserve terminal NeedsAttention/Observed/Unavailable details and mark accepted evidence historical. Reset retires the subscription generation and starts a new epoch after actual plant/controller reset. Disable, scene cleanup and replacement must detach before freeing the runtime. Reopen yields actual fresh home/stopped state but preserves exact valid/invalid saved draft; only validated current bindings permit a new Ready trial.

Do not reset the plant, change commands, acknowledge Done or mutate the controller from observer callbacks. Keep actual timeout and stable hold in accepted time. Historical count is copied from the last validated accepted DINT, not subsequently cleared Stop output points. Currentness and historical fields must distinguish this explicitly.

No architecture blocker requires a broader rewrite. These hooks are necessary implementation guards and must have actual native regressions. Existing intermittent Handle finding remains OPEN; material human approval and wider75 rollout are separate and unapproved.
