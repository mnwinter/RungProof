## Proposed exact integration boundary

These are new design intents, not existing callable APIs. Final contracts may choose names but must retain semantics:

- Presenter to coordinator: RequestTest(currentChallengeId), RequestCancel(runEpoch), RequestStopSimulation(), RequestResetAttempt(), RequestNavigation(destination), RequestClose(), RequestHint(hintId), RequestRevertStarter(challengeId). Revert and navigation are intents routed through existing draft guards. Process Start/Stop use existing interactive input delegation, never worker stimulus callbacks.
- Coordinator to presenter: PresentState(state,runEpoch,workerActive,mutationLocked,pendingAction,statusText); PresentCaseProgress(runEpoch,caseId,index,total); PresentResult(immutableResult,isCurrentProof); PresentCleanupDelay(runEpoch,pendingActionFailed,statusText). Immutable trace/result objects use canonical identity. Optional progress event occurs per case/state, not1750 scan-rate UI updates.
- Editor to coordinator: ExecutableDraftChanged() immediately invalidates displayed current proof; SaveDraftCompleted(path)/SaveDraftFailed(message) report persistence without awarding progress. Read-only selection/watch changes do not fabricate a new executable proof. Final conservative mutation policy governs current-proof invalidation; no hidden restoration after undo without identity check and approved rule.
- Coordinator compiles/freezes/hashes on Test, captures challenge/content identities and epoch, performs pure worker calls, dispatches only main-thread UI, and alone decides award eligibility. Progress save success/failure separately displayed: Passed; progress not saved remains a valid observed test result without a false persistence claim.

Save/Discard/Cancel remains the canonical unsaved-document flow. Cancel initial focus preserved. Imported unsupported programs are InvalidProgram with element/location explanation; they are not wrong solutions. Failed scenario selection highlights historical text/values, while compiler navigation targets current editable document only when identities agree.
