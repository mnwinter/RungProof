## Stop and safety boundary

A normal Stop removes PLC-owned commands according to the scene runtime. This document does not prove a safety function, a real E-stop circuit, a PLC watchdog, or live-machine commissioning.

## Machine guide

A momentary crossing request starts a PLC-owned timed signal sequence over a supported horizontal road and crosswalk.

### Start conditions

- Built-in offline controller with authored or explicitly opened reference logic.
- Initial CROSS released, PATH BLOCK and all commands false. The blank exercise does not start a sequence.

### Normal sequence

- Open .tools/plant-review-pedestrian-crossing.rpproj.json generated by --audit-pedestrian-crossing.
- Run; red/hand startup clearance lasts 3 s. Set PATH CLEAR to release vehicle green.
- Press CROSS: amber, all-red, white WALK, then orange hand/red clearance. PATH BLOCK prevents vehicle release.

### Expected observations

- Two opposing vehicle heads and two far-side pedestrian heads have independent PLC channels.
- ROAD and sidewalks physically support the controls; no people or vehicle motion is simulated.
- This simplified sequence omits the public-road flashing-hand change interval and is not a road controller or timing design.
