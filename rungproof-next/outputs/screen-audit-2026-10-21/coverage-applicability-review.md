# Coverage applicability review

This is a contract-based applicability refinement, not a repair plan or function pass. The eight broad case groups (entry, controls, normal flow, playback, recovery, repeatability, navigation, feedback) remain applicable/open for every scene. App Stop/Reset and output feedback still apply to a lamp lesson. Only narrow feature subchecks below receive N/A where the declared scene/help supplies no such feature. Existing FAIL/BLOCKED and untested cases are retained.

## Rules applied

- **Dedicated scene trip/fault injection:** N/A only when simulation.actions and PC-owned point names expose no fault/trip/emergency/E-stop/overload/alarm route. Where any such route is declared, applicability stays open for its exact control test; existing scoped evidence is retained. This does not remove normal Stop or ordinary permissive checks. If the UI reveals an additional route, revise the N/A.
- **Mechanical process motion:** N/A only for the explicit lamp/counter/selector/manual-arithmetic lessons listed below, whose help describes teaching indications/readouts and whose outputs do not command a process actuator. Button travel, selected-state graphics, lamps and numeric/geometry feedback still require checks. Decorative equipment is not proof of an actuator contract; ambiguous scenes remain open.
- **Interrupting an autonomous intermediate process phase:** N/A only for direct Boolean/selector/manual-arithmetic lessons without a documented autonomous cycle. Input combinations, retained state, rapid/held controls, App Stop/Reset and requalification remain applicable. Counter and timer intermediate observations are not removed.
- No generic controls/recovery/normal-flow case becomes N/A merely because there is no E-stop, no supplied ladder, a diagnostic START blocker, or an unspecified edge policy. A learner prerequisite can be satisfied through UI; a demonstrated blocker remains BLOCKED.
- Missing simultaneous/priority/retention wording is an open expectation for that edge only. It does not block an otherwise clear documented Start/seal/Stop/repeat or truth-table exercise.
